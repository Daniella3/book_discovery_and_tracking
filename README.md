# book_discovery_and_tracking
Full-Stack Web Application | React, MySQL, Google Books API

* Built an interactive book discovery platform enabling users to search, explore, and receive personalized recommendations using the Google Books API
* Designed user-centric reading lists with features for tracking progress, saving favorites, and managing collections
* Developed dynamic recommendation logic based on user searches, genres, and reading behavior 
* Created a responsive and intuitive UI with React, improving user engagement and browsing experience
* Implemented persistent data storage with MySQL to support user-specific lists and activity tracking
